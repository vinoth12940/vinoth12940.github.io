# Vinoth Rajalingam's portfolio

Public portfolio at **https://vinoth12940.github.io/** covering agentic AI, RAG, enterprise CCM, projects, experience, skills, certifications, learning badges, and technical writing.

The existing technical blog remains at **https://vinoth12940.github.io/blog/** in its separate `blog` repository.

## Update content

- `data/profile.json`: professional summary, experience, enterprise solutions, skills, contact links.
- `data/github.json`: verified public project descriptions and repository inventory.
- `data/certifications.json`: credential links, issue and expiry dates, badge assets, and source records.
- `data/writing.json`: Medium links and technical blog archive.

Run `python3 scripts/build.py` to rebuild `index.html`. The site uses static HTML, CSS, and JavaScript and requires no Node dependencies. The generated page also works with JavaScript disabled; JavaScript adds the mobile menu and credential filtering.

## Publishing

GitHub Pages publishes the `main` branch root through its native Pages workflow. Rebuild `index.html` after changing the data, then commit and push the updated files. Each commit to `main` republishes the site.
